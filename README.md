# Don Crock — site

Site do Don Crock (Carpina/PE): frango crocante de verdade.

Acesse: https://galdinoheitor15-star.github.io/don-crock-site/

## Pedidos pelo site

O cliente monta o pedido no cardápio, escolhe **delivery** ou **retirada**, a unidade e a forma de pagamento.
O pedido chega pronto no **WhatsApp da unidade** escolhida.

## Como editar

- **Preços, itens, descrições e opções:** `menu.js` (lista `CARDAPIO`).
- **WhatsApp e endereço das unidades:** `menu.js` (lista `UNIDADES`).
- **Taxa de entrega:** `menu.js` (`TAXA_ENTREGA` — deixe `null` para "a combinar").
- **Fotos dos produtos:** `img/menu/<id-do-item>.webp`.
- **Textos e visual da página:** `index.html`.
